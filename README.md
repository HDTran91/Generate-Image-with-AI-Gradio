This project is an AI-powered Image Generation tool built with Gradio that allows users to create high-quality images from text prompts. Using state-of-the-art generative AI models, users can enter a descriptive sentence, select style and resolution options, and instantly generate unique, realistic, or artistic visuals. The interface is built with Gradio for a simple, interactive, and browser-accessible experience, enabling quick experimentation without complex installations.

Key Features

Text-to-Image Generation: Create images from detailed natural language descriptions.

Customizable Parameters: Control resolution, style, steps, and guidance scale for tailored results.

Live Preview: View generated images instantly in the browser.

Negative Prompt Support: Remove unwanted artifacts or styles from outputs.

User-Friendly Interface: No coding required for end users — just type and generate.

Tech Stack

Frontend: Gradio UI

Backend: Python with AI model integration (e.g., Stable Diffusion, DALL·E, or similar)

Deployment: Local, cloud server, or Hugging Face Spaces
